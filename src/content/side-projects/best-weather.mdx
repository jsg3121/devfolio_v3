## 프로젝트 소개

특정 기간을 목표로 잡아 기술을 이해하고 최대한 완성도를 높이는 챌린지 형식의 프로젝트입니다. Vue 2에서 3으로 올라가며 새롭게 추가된 Composition API를 실제로 적용해보기 위해 시작했고, 프론트엔드뿐 아니라 Docker·Prisma·MySQL을 활용한 서버 구축까지 풀스택으로 확장했습니다.

## 주요 구현

- **Vue 3 Composition API 적용**: Options API에서 Composition API로 전환하며 로직 재사용성과 코드 구조를 개선
- **Docker + Prisma + MySQL 서버 구축**: 기상 정보를 가공·저장하기 위한 백엔드 인프라를 직접 설계하고 구축
- **브라우저 위치 기반 탐지**: Geolocation API로 사용자 위치를 얻고, DB의 좌표 정보와 비교하여 현재 위치를 화면에 표시
- **복수 기상 API 비교**: 기상청 공공데이터와 외부 기상 API를 동시에 호출해 여러 제공사의 정보를 비교·확인할 수 있는 UI 구현
- **사용자 관점 UX 설계**: 주변 지인 및 설문을 통해 사용자가 가장 자주 확인하는 정보(현재 날씨, 최저/최고 기온, 습도, 풍속, 시간별·주간 예보)를 우선 배치

## 배운 점

- Composition API를 통해 Vue의 로직 재사용 패턴을 이해하고, 컴포넌트 설계 방식의 변화를 체감했습니다.
- Docker 기반의 개발 환경 구축과 Prisma ORM을 활용한 데이터 모델링 경험을 통해 백엔드·인프라에 대한 기초적인 이해도를 높였습니다.
- 실제 사용자 설문을 바탕으로 UI를 구성하며, 기능 구현과 사용자 경험 사이의 균형을 고민하는 계기가 되었습니다.
