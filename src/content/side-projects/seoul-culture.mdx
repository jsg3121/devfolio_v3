## 프로젝트 소개

대학교 재학 중 팀 프로젝트로 진행했던 문화공연 정보 공유 서비스를 Vue로 새롭게 만든 프로젝트입니다. Vue의 라이프사이클을 이해하고, 공공데이터를 활용한 비동기 호출과 사용자 중심 UI 기능(슬라이드, 무한 스크롤, 검색 필터)을 직접 구현하는 데 집중했습니다.

## 주요 구현

- **공공데이터 API 비동기 처리**: 서울시 문화행사 공공데이터를 JSON으로 받아 카테고리·조건에 맞는 정보를 화면에 표시
- **Express.js 백엔드 구축**: Express.js로 백엔드를 구성하고, Vue Router와 Vuex Store를 연동하여 필요한 데이터만 선택적으로 요청
- **슬라이드 기능 직접 구현**: API 데이터 길이에 맞게 동적으로 동작하는 슬라이드를 직접 구현
- **무한 스크롤**: 페이지네이션 대신 스크롤 위치 감지를 통해 추가 데이터를 자동으로 로드하는 방식 적용
- **복합 검색 필터**: 카테고리(연주회, 전시회 등), 지역, 날짜를 조합하여 문화행사를 검색할 수 있는 필터 UI 구현
- **열람 히스토리**: 이전에 확인한 문화행사를 사이드바에서 바로 다시 접근할 수 있는 히스토리 기능 구현
- **컴포넌트 분리 설계**: 섹션별 개별 컴포넌트를 구성하여 코드 집중을 최소화하고 유지보수성 확보

## 배운 점

- Vue의 라이프사이클(created, mounted 등)과 렌더링 타이밍을 실제 데이터 요청과 연결하며 이해했습니다.
- Vuex를 통한 전역 상태 관리와 Vue Router를 활용한 페이지 전환 패턴을 익혔습니다.
- 사용자가 정보를 쉽게 탐색할 수 있도록 포스터·기간·카테고리를 중심으로 UI를 구성하며 정보 설계의 중요성을 체감했습니다.

## 지금 돌아보면

당시에는 컴포넌트 분리와 비동기 데이터 흐름을 다루는 것 자체가 도전이었지만, 지금 돌아보면 이 프로젝트에서의 "데이터를 가져와서 조건에 맞게 보여준다"는 경험이 프론트엔드 개발의 가장 기본적인 사고 패턴을 형성하는 출발점이었습니다. 현재의 설계 사고—데이터 레이어 분리, 컴포넌트 역할 정의, 사용자 흐름 중심 UI—의 시작은 이 프로젝트에 있습니다.
